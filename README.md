# In the margins.

A personal journal by Subhro. Everyday observations, longer writing, and passing thoughts. 

Read it live: [https://comet-core.github.io/blog](https://comet-core.github.io/blog)

## About this repository

This is the source code for my personal journal, built with [Eleventy](https://www.11ty.dev/). It is intentionally lightweight, serving static HTML, CSS, and minimal vanilla JavaScript with no backend or database.

## Topics

- **Everyday** — Things seen, heard, and almost missed.
- **Writings** — Thoughts that need a little more room.
- **Fragments** — Lists, stray lines, and the beautifully unfinished.
- **Space** — Cosmos, night skies, and looking upward.
- **Automotive** — Machines in motion, cars, planes, and all things mechanical.

## Local Development

To run this site locally:

1. Clone the repository: `git clone https://github.com/comet-core/blog.git`
2. Install dependencies: `npm install`
3. Run the local development server: `npm run dev`
